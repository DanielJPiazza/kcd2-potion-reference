# Henry's Alchemy Restock (KCD2)

A lightweight, standalone web app designed to help players plan and track potion crafting in *Kingdom Come: Deliverance II*. It automatically calculates total ingredients needed and provides step-by-step brewing instructions for each potion.

## Web App

Access the tool directly in your browser:  
[https://danieljpiazza.github.io/kcd2-potion-reference/](https://danieljpiazza.github.io/kcd2-potion-reference/)

## Features

* **Dynamic Shopping List**: Calculates the exact quantities of ingredients required based on your desired potion yields.
* **Step-by-Step Brewing Recipes**: Expandable cards displaying exact grinding, boiling duration (turns), and bellows instructions.
* **Dark Medieval Theme**: Stylized UI matching the aesthetic of *Kingdom Come: Deliverance* using modern CSS custom properties and flexible layouts.
* **Zero Dependencies**: Pure HTML, CSS, and vanilla JavaScript—no build tools, NPM packages, or external dependencies required.

## Supported Potions

* **Aqua Vitalis**: Health loss & bleeding reduction
* **Artemisia**: Strength booster
* **Bane (Poison)**: Lethal poison
* **Buck's Blood**: Stamina & stamina regeneration boost
* **Fox**: Speech, reading speed, and XP gain boost
* **Hair o' the Dog**: Drunkenness & hangover reduction
* **Marigold Decoction**: Health healing & hangover cure
* **Painkiller**: Wound effect & stamina loss reduction
* **Quickfinger**: Thievery & craftsmanship booster
* **Saviour Schnapps**: Manual game save & physical stat booster
